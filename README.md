# 长沙麻将算分器

手机上用的长沙麻将记账算分工具。单页网页（HTML/JS 全离线），可「添加到主屏幕」当 App 用。

打开：https://tigerzhou87-bot.github.io/changsha-mahjong-score/

## 本桌规则（默认值，点「设置」可改）

- **只准自摸**，三家全付；底分 **5 毛/分**
- 小胡：基础 **2 分/家**
- 大胡：**8 分 × 个数**（1个8、2个16、3个24、4个32 …… 算加法，不封顶）
- **扎鸟**：胡后摸两张鸟 —— **1·5·9 中自己**（三家全翻倍）；**2·6 下家 / 3·7 对家 / 4·8 上家**（只有那家翻倍）。两只都中自己 = 翻两番（×4）。所以小胡：中一鸟 4 分、两鸟都中自己 8 分。
- 杠：明杠每家 **1 分**（5毛）、暗杠每家 **2 分**（1块），逐个累计（一杠到底）
- 庄家：不算

## 用法

1. 手机浏览器打开上面链接 → 分享/菜单 →「添加到主屏幕」
2. 先花半分钟：点右上角「✏️ 改名字」，**按出牌顺序绕圈填**四个人（第二格是第一个人的下家）——工具靠这个把「2·6 下家」认对人
3. 每打完一局：点胡的人 → 小胡直接下一步 / 大胡勾番型（自动 8×个数）→ **点两张鸟中谁** → 有杠加减 → 结算 → 确认
4. 预演那行会实时显示每家付多少，先核对再入账；点错可撤销；「结束清账」开下一桌
