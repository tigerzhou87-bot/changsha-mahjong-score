# 长沙麻将算分器

手机上用的长沙麻将记账算分工具。单页网页（HTML/JS 全离线），可「添加到主屏幕」当 App 用。

打开：https://tigerzhou87-bot.github.io/changsha-mahjong-score/

## 本桌规则（默认值，点「设置」可改）

- **只准自摸**，三家全付；底分 **5 毛/分**
- 小胡：**2 / 4 / 8 分**（每家）
- 大胡：**8 / 16 / 24 / 32 分**（每家）；多一个大胡 **+8 分**（算加法，不封顶）
- 杠：明杠每家 **1 分**、暗杠每家 **2 分**，逐个累计（一杠到底）
- 庄家自摸 ×2：可选（默认关）

## 用法

1. 手机浏览器打开上面链接 → 分享/菜单 →「添加到主屏幕」
2. 每打完一局：点胡家的人 → 点胡型分值 → 有杠加减 → 结算 → 确认入账
3. 大胡可用「按番型自动算」：勾碰碰胡/清一色等，自动按 8×个数 累计
4. 顶部「记分」看四家输赢；「结束清账」开下一桌

记录只保存在这台手机浏览器里，不上传。
